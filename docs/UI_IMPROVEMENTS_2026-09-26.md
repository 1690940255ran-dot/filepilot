# FilePilot 界面与功能完善（2026-09-26）

本轮按用户确认的简洁 Windows 桌面工具风格实施，完善现有整理流程。采用 Superpowers 的需求梳理、先失败后修复的行为测试和完成前验证流程。

## 已实施

- 左侧导航、文件夹品牌图形、统一蓝色主操作、浅灰工作区和白色卡片；统一设置、历史、撤销和恢复区域的表单、间距、边框与反馈。
- 首页增加步骤提示和三列扫描统计；把后端已有的 `byMonth` 规则接到「按修改月份」选项，按类型仍是默认值。月份依据是最后修改时间。
- 预览支持按源路径或目标路径搜索，以及「全部 / 仅看有问题的 / 仅看已选中的」筛选。
- 支持批量取消当前筛选结果的选择；隐藏项不受影响，修改后原确认失效，仍须应用修改并重新校验。不会通过筛选自动选中原本未选择的项。
- 预览表直接显示整理理由，来源和目标分列显示，长路径保留完整文本和悬停提示；空搜索结果有明确提示。
- 修复虚拟列表滚动后筛选为短列表时因旧偏移越界而显示空白的问题。
- 保存或执行过程中禁用勾选、目标修改和批量取消，防止响应返回时丢失用户在请求期间追加的修改。
- 换一份计划时重置预览组件，避免旧结果和筛选状态进入新计划；切换页面回到内容顶部。
- 适配较小窗口，保留清晰键盘焦点和减少动态效果偏好；补齐原先未定义的历史/撤销颜色变量。
